# Italiano Giocando · Missione Verbi

Игра для практики итальянских глаголов в настоящем времени (Presente indicativo), уровень A1–A2.

**[Открыть игру](https://shdenisd.github.io/italiano-giocando-missione-verbi/)**

10 глаголов, 60 форм, 120 разных предложений, 16 этапов: изучение, смешанные миссии и финал. Есть повторение ошибок, задания на сегодня, озвучка и отчёт для преподавателя.

## Как пользоваться

Откройте ссылку на игру в браузере телефона или компьютера. Регистрация и установка не требуются.

Прогресс хранится в браузере на текущем устройстве. Для переноса используйте экспорт и импорт в разделе «Настройки и данные». Озвучка зависит от поддержки синтеза речи браузером и наличия итальянского голоса.

Особенность исходной версии v7: после перезагрузки список завершённых этапов сбрасывается; XP, ошибки и статистика сохраняются.

## Локальный запуск

Скачайте репозиторий и откройте `index.html` в браузере. Для публикации не нужны сборка, зависимости или сервер.

## Публикация

Сайт размещён на GitHub Pages из корня ветки `main`. Изменения в этой ветке публикуются автоматически.

В основу взят файл `index.html` из архива `Italiano_Giocando_Missione_Verbi_v7.zip` без изменений.
